# Chaos Poker

Покер для компании друзей: техасский холдем плюс карты событий, способности, побочные ставки, задания (в том числе фото), физические активности и судья — человек, ИИ или никто. Сервер работает на ноутбуке, все играют со своих телефонов, подключаясь по QR-коду.

- **Ведущий (host)** — главный телефон или планшет: общий стол, банк, события, лента, фото.
- **Диллер (судья)** — необязательный отдельный телефон: события, задания, указы, штрафы, проверка фото.
- **Игроки** — до 8 телефонов: свои карты, ставки, способности, задания.

---

## 1. Что понадобится

- Ноутбук с Windows, macOS или Linux и **Python 3.11+** ([python.org](https://www.python.org/downloads/); на Windows при установке отметьте «Add python.exe to PATH»).
- Одна **Wi‑Fi сеть** для ноутбука и всех телефонов.
- Для ИИ-судьи (необязательно): интернет на ноутбуке и ключ GigaChat API — раздел 6.

## 2. Установка (один раз)

Откройте терминал (на Windows — PowerShell) в папке проекта `JOKER`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # macOS / Linux: source .venv/bin/activate
pip install -r chaos_poker/requirements.txt
```

> Если PowerShell пишет, что выполнение сценариев отключено: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем повторите активацию.

Скопируйте `.env.example` в `.env` (в той же папке `JOKER`). Без ключа GigaChat всё работает — ИИ просто говорит заготовленными фразами.

## 3. Запуск

```powershell
.\.venv\Scripts\Activate.ps1
cd chaos_poker
python run.py
```

`run.py` сам:
1. определяет IP ноутбука в Wi‑Fi (адреса VPN пропускает);
2. при первом запуске создаёт HTTPS-сертификат в `chaos_poker/certs/` для этого IP (нужен `openssl` — он есть в Git для Windows, macOS и Linux);
3. запускает сервер на `https://<IP>:8443` и показывает QR-код ведущего — в окне и прямо в терминале.

Без окна: `python run.py --no-gui`. Остановить сервер — `Ctrl+C` или закрыть окно с QR-кодом.

### Как проходит игра

1. **Ведущий** сканирует QR-код из окна `run.py` — на телефоне открывается лобби.
2. В лобби настройте игру (стек, блайнды, уровень хаоса, режим диллера и т. д.) и нажмите «Применить настройки».
3. **Диллер** (если играете с судьёй-человеком) сканирует первый QR-код. Он одноразовый.
4. **Игроки** сканируют второй QR-код, вводят имя, выбирают аватар и соглашаются на камеру и показ фото.
5. Ведущий нажимает «Начать игру» (нужно минимум 2 игрока).

Если телефон перезагрузил страницу — он вернётся на своё место автоматически.

## 4. HTTPS и предупреждение о сертификате

HTTPS обязателен: без него браузер не даёт камеру для фото-заданий. Есть два варианта.

**Вариант А — как есть (быстро).** `run.py` создаёт самоподписанный сертификат. Телефон предупредит «Подключение не защищено»:
- Android / Chrome: «Дополнительные» → «Перейти на сайт».
- iPhone / Safari: «Показать подробности» → «посетить этот веб-сайт».

> На iPhone так иногда не работает живое соединение с игрой (WebSocket): страница открывается, но стол не обновляется. Тогда используйте вариант Б или туннель (раздел 7).

**Вариант Б — mkcert (без предупреждений, рекомендуется для iPhone).**

1. Установите [mkcert](https://github.com/FiloSottile/mkcert): на Windows `winget install FiloSottile.mkcert` (или `choco install mkcert`), на macOS `brew install mkcert`.
2. В папке `chaos_poker` выполните (подставьте IP ноутбука — его печатает `run.py`):
   ```powershell
   mkcert -install
   mkcert -cert-file certs/cert.pem -key-file certs/key.pem 192.168.0.104 localhost 127.0.0.1
   ```
3. Установите корневой сертификат mkcert на телефоны. Где он лежит: `mkcert -CAROOT` (файл `rootCA.pem`).
   - **Android:** перешлите `rootCA.pem` на телефон → «Настройки» → «Безопасность» → «Шифрование и учётные данные» → «Установить сертификат» → «Сертификат ЦС».
   - **iPhone:** отправьте `rootCA.pem` себе (AirDrop / почта) → откройте → «Настройки» → «Профиль загружен» → «Установить». Затем «Основные» → «Об этом устройстве» → «Доверие сертификатам» → включите доверие для mkcert.

`run.py` никогда не трогает сертификат, сделанный вами. Свой сертификат он перевыпускает сам, когда меняется IP ноутбука.

## 5. Файрвол (если телефон не открывает страницу)

- **Windows:** сеть Wi‑Fi должна быть «Частной» («Параметры» → «Сеть и Интернет» → ваша сеть → «Частная сеть»). Затем в PowerShell **от имени администратора**:
  ```powershell
  New-NetFirewallRule -DisplayName "Chaos Poker" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow -Profile Private
  ```
  Также можно просто нажать «Разрешить доступ», когда Windows спросит при первом запуске.
- **macOS:** при первом запуске разрешите входящие подключения для Python.
- **Linux (ufw):** `sudo ufw allow 8443/tcp`.

Проверка: на ноутбуке откройте `https://localhost:8443/health` — должно быть `{"status":"ok"}`. Потом с телефона: `https://<IP ноутбука>:8443/health`.

## 6. ИИ-судья (GigaChat, необязательно)

1. Зарегистрируйтесь в [личном кабинете GigaChat API](https://developers.sber.ru/studio/) → создайте проект GigaChat API → **Настройки API** → «Получить ключ». Скопируйте **Authorization key** (показывается один раз).
2. Вставьте его в `.env`: `GIGACHAT_AUTH_KEY=...`. Для физлиц scope `GIGACHAT_API_PERS` (уже указан).
3. Скачайте **корневой сертификат Минцифры** (Russian Trusted Root CA) на [Госуслугах](https://www.gosuslugi.ru/crt) и положите его как `chaos_poker/certs/russian_trusted_root_ca.pem`. Он нужен только для запросов к GigaChat. Если скачался `.cer`, переведите в PEM:
   ```powershell
   openssl x509 -inform der -in russian_trusted_root_ca.cer -out chaos_poker/certs/russian_trusted_root_ca.pem
   ```
4. Перезапустите `run.py`. В консоли появится «ИИ-судья: готов», а в лобби ведущего — индикатор, расход токенов и кнопка «Проверить ИИ».
5. В настройках лобби выберите режим диллера «ИИ».

Что делает ИИ-судья: комментирует раздачи (на телефоне ведущего можно включить озвучку), выбирает события **только из каталога** и объясняет выбор, придумывает штрафы и бонусные задания, принимает или отклоняет взятки, пишет итоговый протокол вечера с номинациями. Если ключа нет, нет сети или кончился лимит (`GIGACHAT_TOKEN_BUDGET` на партию) — игра не ждёт и сразу берёт заготовки из `chaos_poker/data/`.

Приватность: в GigaChat уходят никнеймы и ход раздач; карманные карты и фото **не** передаются. Ключ и токен не попадают в логи.

## 7. Альтернатива: туннель

Если телефоны в разных сетях, файрвол не настраивается или iPhone не доверяет сертификату — откройте игру через туннель с настоящим сертификатом.

**Cloudflare Tunnel** (бесплатно, без регистрации для быстрых туннелей):
```powershell
cloudflared tunnel --url https://localhost:8443 --no-tls-verify
```
Скопируйте выданный адрес `https://....trycloudflare.com`, впишите его в `.env` как `PUBLIC_URL=https://....trycloudflare.com` и перезапустите `run.py` — QR-коды будут вести на туннель.

**ngrok:** `ngrok http https://localhost:8443`, дальше так же через `PUBLIC_URL`.

## 8. Режимы и настройки

| Режим диллера | Кто ведёт |
|---|---|
| Человек | Отдельный телефон судьи: события, задания (свой текст / банк / ИИ), фото-задания, указы, штрафы до 2 BB, проверка заданий и фото |
| ИИ | GigaChat (или заготовки). Задания и активности игрок подтверждает сам. Фото-заданий нет |
| Без диллера | События случайные, задания подтверждаются голосованием остальных игроков, фото-заданий нет |

| Уровень хаоса | Что включено |
|---|---|
| light | Событие каждую 3-ю раздачу; без способностей и побочных ставок |
| medium | Событие каждую 2-ю раздачу; способности и побочные ставки |
| full | Событие каждую раздачу; всё включено |

Физические активности (шейк-баттл, «Замри», дуэль, приседания, стоячий стол) включаются в лобби: `off | light | medium | hard`. Датчики телефона не нужны — результат подтверждает диллер, при ИИ-судье — сам игрок, без диллера — голосование.

## 9. После игры

На экране ведущего: места и стеки, статистика (победы, блефы, крупнейший банк, способности, задания), протокол вечера с номинациями и **альбом** — фото, которые игроки сохранили. Скачайте альбом кнопкой «⬇ Скачать альбом (.zip)», затем нажмите «Закрыть комнату» — фото удалятся (кроме альбома). Фото старше 24 часов сервер удаляет сам.

## 10. Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Телефон не открывает страницу | Та же Wi‑Fi сеть? Файрвол (раздел 5). IP в ссылке — тот, что печатает `run.py`? Если IP неверный (VPN, несколько сетей) — укажите `HOST_IP=...` в `.env` |
| «Подключение не защищено» | Нормально для варианта А — «Перейти на сайт». Без предупреждений — mkcert (раздел 4) |
| Страница открылась, но стол не обновляется (iPhone) | mkcert или туннель (разделы 4, 7) |
| `Не удалось создать HTTPS-сертификат` | Установите Git для Windows или сделайте сертификат через mkcert |
| ИИ: «Нет сертификата Минцифры» | Раздел 6, шаг 3 |
| ИИ: «Неверный ключ авторизации или scope» | Проверьте `GIGACHAT_AUTH_KEY` и `GIGACHAT_SCOPE` |
| ИИ: «Нет соединения с GigaChat» | Нет интернета или порт 9443 закрыт сетью — игра идёт на заготовках |

Журнал действий (без карт и секретов): `chaos_poker/logs/chaos_poker.log`.

## Для разработчика

```powershell
cd chaos_poker
python -m pytest -q
```

- `app/game/` — чистая логика без сети: движок холдема, оценка рук, банки, события, способности, побочные ставки.
- `app/models.py` — комната и ход партии; `app/views.py` — что видит каждая роль (чужие карты не отправляются никогда).
- `app/tasks/` — задания, фото, физические активности; `app/dealer/` — судья-человек, ИИ-судья, GigaChat-клиент и токены.
- `app/main.py` — HTTP и WebSocket; `static/` — страницы host, dealer, play.
- Каталоги и резервный контент: `data/*.json`. Техническое задание: `TZ_chaos_poker.md`.
