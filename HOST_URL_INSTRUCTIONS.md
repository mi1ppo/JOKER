# Как открыть игру с телефона — коротко

Полная инструкция — в [README.md](README.md). Здесь только шпаргалка.

1. На ноутбуке:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   cd chaos_poker
   python run.py
   ```
2. `run.py` сам определит IP ноутбука в Wi‑Fi и покажет **QR-код ведущего** (в окне и в терминале). Отсканируйте его главным телефоном — откроется лобби. Вручную искать IP через `ipconfig` не нужно.
3. В лобби будут QR-коды для диллера и игроков — их сканируют остальные телефоны.
4. Предупреждение «Подключение не защищено» — нормально для автоматического сертификата: «Дополнительные» → «Перейти на сайт». Без предупреждений — mkcert (README, раздел 4).

Не открывается? По порядку:
- телефон и ноутбук в одной Wi‑Fi сети;
- порт 8443 открыт в файрволе (README, раздел 5);
- в ссылке тот IP, что печатает `run.py`; если там адрес VPN или не той сети — впишите нужный в `.env`: `HOST_IP=192.168.0.104`;
- проверка: `https://localhost:8443/health` на ноутбуке и `https://<IP>:8443/health` с телефона должны показать `{"status":"ok"}`.
